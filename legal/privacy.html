隐私政策

最后更新：2026年1月20日

English Version

感谢您选择 Immerse AI。我们深知个人信息对您的重要性，并致力于保护您的隐私。本隐私政策旨在向您说明我们如何收集、使用和保护您的信息。

1. 信息收集

在使用 Immerse AI 过程中，我们可能会收集以下信息：

  • 账户信息： 当您注册或登录时，我们会收集您的电子邮件地址及第三方登录（如 Google, Linux.do）提供的公开基本信息。
  • 学习数据： 为了提供核心功能，我们会保存您的单词本、学习进度、XP经验值和成就。这些数据通过 Chrome Sync 或我们的加密云端同步。
  • 使用统计： 我们收集匿名的性能指标（如 API 响应时间）和使用深度（如翻译的单词数量），以优化算法和产品体验。

2. 如何使用信息

收集的信息主要用于以下场景：

  • 同步您的跨设备学习进度。
  • 通过 AI 推荐适合您等级的词汇。
  • 根据您的偏好自定义沉浸比例和主题风格。
  • 处理订阅支付并提供相应等级的服务。

3. 关于 AI 处理

Immerse AI 涉及文本解析与翻译。当您使用划词翻译或全文翻译功能时：

  • 部分内容会发送至 AI 服务提供商（如 OpenAI, Anthropic, Gemini 等）进行处理。
  • 我们仅发送处理所需的最小文本段落，且不附带您的身份标识。
  • 若您提供自定义 API Key (BYOK)，相关请求将直接发往服务商，我们不存储您的私有密钥。

4. 数据安全

我们采用行业标准的加密技术（TLS/SSL）保护数据传输。您的生词本数据经过哈希处理和多重备份。我们承诺绝不将您的个人数据出售给任何第三方营销机构。

5. 您的权利

您拥有以下权利：

  • 导出数据： 随时通过插件设置导出所有生词本数据。
  • 删除账户： 通过插件设置或注销账户来删除您的所有云端数据。
  • 撤回授权： 撤回授权并停止一切数据同步。

6. 联系我们

如果您对本政策有任何疑问，请通过以下方式联系我们：

  • 邮件：support@immerse.ai
  • GitHub Issues: https://github.com/JHdehao/immerse-website/issues
